# FIRE-001 — 2D Environment & Wildfire Zones

**Sprint:** Ημέρες 2–14 · **Επίπεδο:** Beginner core + optional advanced · **Ενδεικτικό αρχείο:** `firenav/scenarios.py`

## 🎓 Γιατί το κάνουμε;
Υλοποίησε ένα μικρό deterministic update της πυρκαγιάς και έλεγχο ότι παραμένει σε επιτρεπτά κελιά. Στον χάρτη υπάρχουν ήδη η βάση, ο στόχος, στατικά εμπόδια και αρχικά κελιά φωτιάς.

**Σύνδεση με Μαθηματικά:** Γεωμετρία, Σύνολα, Μαθηματική Μοντελοποίηση

## 🔎 Τι είναι ήδη έτοιμο;
Το `spread_fire_once(mission)` αρχικά δεν μεταβάλλει το σύνολο `mission.fire`. Έλεγξε τον ορισμό του `Mission` και εφάρμοσε **μία** προβλέψιμη αλλαγή, χωρίς εξωτερικά δεδομένα.

## 🪜 Πάμε βήμα-βήμα
1. Διάβασε τον οδηγό [START HERE](../docs/START_HERE_GR.md) στο repository και τρέξε την εφαρμογή.
2. **Κατανόηση:** Δες `Mission.fire`, `Mission.inside` και το demo. Γράψε δικό σου unit test πριν αλλάξεις τη συνάρτηση.
3. Δημιούργησε στο δικό σου repository ένα branch `feature/fire-001`.
4. Κάνε μια μικρή αλλαγή με ένα test, τρέξε τη σουίτα, κάνε commit.
5. Επανέλαβε μέχρι να ικανοποιούνται **όλα** τα acceptance criteria.
6. Κάνε push → προσωπικό PR → περιγραφή μαθηματικής λογικής → merge.

## ✅ Acceptance criteria
- [ ] Ένα πάτημα SPREAD FIRE μεταβάλλει το `mission.fire` και η αλλαγή απεικονίζεται.
- [ ] Κανένα κελί εκτός χάρτη, στη βάση, στον στόχο ή σε στατικό εμπόδιο δεν γίνεται φωτιά.
- [ ] Ίδια αρχική κατάσταση → ίδιο αποτέλεσμα (deterministic).
- [ ] Πρόσθεσε tests για όρια/μη επιτρεπτές θέσεις.

## 💡 Πρώτη υπόδειξη (όχι λύση)
Πρώτα γράψε `new_fire = set(mission.fire)`. Έπειτα βρες υποψήφιο γειτονικό κελί και έλεγξε `mission.inside(...)` πριν το προσθέσεις.

## 🎯 Τι θα εξηγήσεις στην παρουσίαση;
Δείξε ένα πραγματικό input, την αναμενόμενη έξοδο, ένα edge case, το σχετικό test και ποια μαθηματικά χρειάστηκες.
