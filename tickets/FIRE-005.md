# FIRE-005 — 2D Mission Dashboard & Animated Execution

**Sprint:** Ημέρες 16–29 · **Επίπεδο:** Beginner core + optional advanced · **Ενδεικτικό αρχείο:** `app.py`

## 🎓 Γιατί το κάνουμε;
Βελτίωσε το υπάρχον Tkinter UI ώστε να απεικονίζει την **αληθινά υπολογισμένη** τροχιά, την πρόοδο αποστολής και αλλαγές της φωτιάς. Η υπάρχουσα επιλογή SCRIPTED DEMO είναι μόνο animation δείγματος.

**Σύνδεση με Μαθηματικά:** Αναλυτική Γεωμετρία, Οπτικοποίηση, Human–Computer Interaction

## 🔎 Τι είναι ήδη έτοιμο;
Υπάρχει ήδη canvas, χρώματα, legend labels, controls και info panel. Το πραγματικό mission execution loop δεν είναι έτοιμο.

## 🪜 Πάμε βήμα-βήμα
1. Διάβασε τον οδηγό [START HERE](../docs/START_HERE_GR.md) στο repository και τρέξε την εφαρμογή.
2. **Κατανόηση:** Πρώτα εμφάνισε ένα σωστό route στο canvas, μετά πρόσθεσε animation και ενημέρωση metrics.
3. Δημιούργησε στο δικό σου repository ένα branch `feature/fire-005`.
4. Κάνε μια μικρή αλλαγή με ένα test, τρέξε τη σουίτα, κάνε commit.
5. Επανέλαβε μέχρι να ικανοποιούνται **όλα** τα acceptance criteria.
6. Κάνε push → προσωπικό PR → περιγραφή μαθηματικής λογικής → merge.

## ✅ Acceptance criteria
- [ ] Κουμπί START μετά την ολοκλήρωση FIRE-002/003 εκτελεί ασφαλή βήματα πραγματικής προγραμματισμένης πορείας.
- [ ] Ο χάρτης δείχνει base, target, obstacles, fire, route, current position.
- [ ] Με replanning η μπλε διαδρομή ενημερώνεται χωρίς ψευδή teleport.
- [ ] Το panel δείχνει θέση, battery, state, μήκος υπόλοιπης διαδρομής και τελευταίο event.
- [ ] Αποτυπώνει σαφή αποτυχία όταν η αποστολή σταματά, δεν την παρουσιάζει ως επιτυχία.
- [ ] Το UI δεν μπλοκάρει σε μεγάλα loops· χρήση `root.after` για animation.

## 💡 Πρώτη υπόδειξη (όχι λύση)
Πάρε ως πρότυπο τον `tick_demo`, αλλά στην πραγματική αποστολή να καλείς `move_one_step` και να ελέγχεις κατάστασή της.
