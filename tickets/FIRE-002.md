# FIRE-002 — Mission State, Movement, Battery & Safe Return

**Sprint:** Ημέρες 2–14 · **Επίπεδο:** Beginner core + optional advanced · **Ενδεικτικό αρχείο:** `firenav/mission.py και firenav/model.py`

## 🎓 Γιατί το κάνουμε;
Το drone πρέπει να πηγαίνει από βάση σε σημείο παρατήρησης και να επιστρέφει. Υλοποίησε ξεκάθαρες καταστάσεις αποστολής, ενημέρωση μπαταρίας σε εκπαιδευτικές μονάδες και safe return.

**Σύνδεση με Μαθηματικά:** Φυσική, Διακριτός Χρόνος, Μαθηματική Μοντελοποίηση

## 🔎 Τι είναι ήδη έτοιμο;
Τα `start_rescue_observation`, `request_return_to_base` είναι κενά ως προς τη συμπεριφορά. Η `move_one_step` ήδη κάνει βασικό έλεγχο αποδεκτών 4-γειτονικών κινήσεων.

## 🪜 Πάμε βήμα-βήμα
1. Διάβασε τον οδηγό [START HERE](../docs/START_HERE_GR.md) στο repository και τρέξε την εφαρμογή.
2. **Κατανόηση:** Ξεκίνα με διάγραμμα `READY → FLYING → TARGET_REACHED → RETURNING → COMPLETED`, πρόσθεσε ABORTED.
3. Δημιούργησε στο δικό σου repository ένα branch `feature/fire-002`.
4. Κάνε μια μικρή αλλαγή με ένα test, τρέξε τη σουίτα, κάνε commit.
5. Επανέλαβε μέχρι να ικανοποιούνται **όλα** τα acceptance criteria.
6. Κάνε push → προσωπικό PR → περιγραφή μαθηματικής λογικής → merge.

## ✅ Acceptance criteria
- [ ] Έγκυρη αποστολή ξεκινά μόνο αν ο planner δώσει βατή διαδρομή.
- [ ] Αποστολή δεν ξεκινά χωρίς επαρκές **συντηρητικό** ενεργειακό απόθεμα για επιστροφή.
- [ ] Άκυρες κινήσεις, μηδενική μπαταρία και χαμένη ασφαλής πορεία καταλήγουν σε σαφή safe failure.
- [ ] Η επιστροφή τερματίζει στη βάση με κατάσταση COMPLETED.
- [ ] Tests καλύπτουν start, target, return, low battery και unavailable route.

## 💡 Πρώτη υπόδειξη (όχι λύση)
Χρησιμοποίησε ως αρχική προσέγγιση `1 unit/βήμα` και κράτησε reserve. Προσοχή: Manhattan απόσταση είναι μόνο κάτω φράγμα, όχι εγγυημένη επιστροφή γύρω από εμπόδια.
